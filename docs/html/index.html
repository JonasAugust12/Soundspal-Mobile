Nội dung

Soundspal · TL-Mobile · v1.0.28

Tài liệu kỹ thuật

Toàn bộ tài liệu về ứng dụng di động Soundspal: kiến trúc, luồng dữ liệu, từng tính năng hoạt động ra sao, công nghệ nào dùng ở đâu, và cách dựng lại mọi dịch vụ bên thứ ba từ con số không.

Chưa quen dự án? Đọc theo thứ tự này 1. Kiến trúc dự án (hiểu bộ khung) → 2. Một tài liệu tính năng bất kỳ bạn sắp làm việc → 3. Công nghệ sử dụng (tra cứu khi cần) → 4. Setup bên thứ ba (khi cần dựng môi trường hoặc phát hành).

Tài liệu nền tảng

Tài liệu 01

Kiến trúc dự án

Cấu trúc thư mục, vai trò từng file, ba tầng Clean Architecture, và đường đi của dữ liệu từ màn hình xuống backend rồi quay lại. Kèm luồng khởi động app và cơ chế refresh token.

Tài liệu 02

Công nghệ sử dụng

Mỗi thư viện trong package.json: dùng ở file nào, dùng thế nào, và vì sao chọn nó. Có bản đồ tra cứu nhanh "thư viện → file".

Tài liệu 03

Setup bên thứ ba & Auto Deploy

Hướng dẫn thao tác thật: Google Cloud, Firebase FCM, Google Sign-In, PayOS, Socket.IO, EAS Build, Google Play Console, Fastlane. Kèm bảng lỗi thường gặp và checklist dựng lại từ số 0.

Tài liệu tính năng

Mỗi tài liệu mô tả: luồng đi trong code, business logic, danh sách endpoint, mô hình dữ liệu, các bẫy đã biết và những chỗ cần cải thiện.

features/auth

Xác thực & Tài khoản

Đăng ký, đăng nhập, OTP xác thực email, quên mật khẩu 3 bước, đăng nhập Google, đổi email. Vòng đời token và guard điều hướng.

features/profiles

Hồ sơ người dùng

Hồ sơ nghệ sĩ vs venue — hai thế giới tách biệt. 29 endpoint, 11 màn hình, upload ảnh, thư viện media, phần trăm hoàn thiện hồ sơ.

features/jobs

Tuyển dụng & Ứng tuyển

Feature lớn nhất: đăng tin (wizard 4 bước), tìm & lọc, ứng tuyển, duyệt hồ sơ, vòng đời trạng thái bài đăng.

features/collab

Quản lý hợp tác

Đơn đã gửi & bài đăng của tôi. Dùng lại API của jobs bằng lớp code riêng — và những hệ quả cần biết.

features/messaging

Nhắn tin thời gian thực

Chat qua WebSocket: tin nhắn tức thời, đang gõ, online, đã xem, đính kèm, và giao thức thẻ công việc JOB_REF.

features/notifications

Thông báo đẩy (FCM)

Ít code nhất nhưng nhiều bẫy nhất: quyền Android 13+, ba trạng thái app, điều hướng khi bấm, và ràng buộc với socket.

features/payments

Thanh toán Premium (PayOS)

Nâng cấp qua VietQR: tạo checkout, deep link trả về, cơ chế poll trạng thái, và cách đọc trạng thái Premium cho đúng.

features/blog

Blog & Bình luận

Đọc/viết bài, bình luận phân cấp, lưu bài. Luồng tạo bài 4 bước và lớp chuẩn hoá response nhiều tầng.

features/challenge

Challenge & Phòng thu

Đăng beat, thu âm đè lên beat, AI chấm 6 tiêu chí, bình chọn, bảng xếp hạng. Toàn bộ pipeline âm thanh.

home · explore · search

Trang chủ · Khám phá · Tìm kiếm

Trang chủ tổng hợp, tìm người theo bộ lọc, tìm kiếm gộp, và MiniPlayer nghe beat.

Tra cứu nhanh

Ứng dụng này là gì?

Nền tảng kết nối ngành âm nhạc trên di động, xây bằng React Native + Expo, kiến trúc Clean Architecture theo feature. Ba nhóm người dùng:

Vai trò Là ai Dùng app để
singer Ca sĩ / nghệ sĩ biểu diễn Tạo hồ sơ, ứng tuyển gig, thu âm challenge, nhắn tin
producer Nhà sản xuất / beatmaker Đăng beat, tạo challenge, nhận cộng tác
venue Quán bar / phòng trà / sự kiện Đăng tin tuyển, duyệt hồ sơ ứng tuyển, liên hệ nghệ sĩ

Tôi muốn sửa X, mở file nào?

Muốn sửa Mở
Địa chỉ backend, socket, Google client id .env (rồi npm run start:clear)
Cách gọi API, gắn token, xử lý 401 shared/infrastructure/api/apiClient.ts
Sự kiện realtime shared/infrastructure/socket/socketService.ts
Luật điều hướng khi chưa đăng nhập / chưa xác thực shared/presentation/hooks/useProtectedRoute.ts
Danh sách endpoint của một feature features/<tên>/data/datasources/*RemoteDataSource.ts
Màu sắc, font, design token tailwind.config.js
Component dùng chung shared/presentation/ui/
Thêm màn hình mới features/<tên>/presentation/screens/ + file route một dòng trong app/
Cấu hình native (icon, splash, package, plugin) app.json
Quy trình build & phát hành eas.json, fastlane/Fastfile, .github/workflows/eas-build.yml

Lệnh hay dùng

# Phát triển
npm install
npm run start:clear        # khởi động Metro, xoá cache (dùng sau khi sửa .env)
npm run android            # chạy trên Android
npm run ios                # chạy trên iOS

# Kiểm tra chất lượng
npm run lint
npm run typecheck
npm test

# Build
npm run build:android:dev  # development build (BẮT BUỘC — Expo Go không chạy được)
npm run build:android:prod # .aab production

# Phát hành (tự động toàn bộ)
fastlane android trigger_release
Dự án này KHÔNG chạy được trên Expo Go Có 3 native module không có trong Expo Go: @react-native-firebase/*, react-native-mmkv, @react-native-google-signin/google-signin. Bắt buộc phải dùng development build.

Bảy biến môi trường

Biến Đọc bởi
EXPO_PUBLIC_API_BASE_URL apiClient.ts
EXPO_PUBLIC_AUTH_REFRESH_URL apiClient.ts
EXPO_PUBLIC_SOCKET_URL socketService.ts
EXPO_PUBLIC_SOCKET_PATH socketService.ts
EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID useGoogleSignIn.ts
EXPO_PUBLIC_STORAGE_ID storage.ts
EXPO_PUBLIC_STORAGE_ENCRYPTION_KEY storage.ts
Tiền tố EXPO_PUBLIC_ nghĩa là công khai Giá trị bị nhúng thẳng vào file .apk/.ipa. Nó dùng để tách môi trường, không phải kho bí mật. Không đặt mật khẩu, client_secret hay private key vào đây.

Những điều dễ gây bất ngờ

Tổng hợp các chi tiết trái với trực giác, thu thập từ toàn bộ tài liệu. Biết trước sẽ tiết kiệm nhiều giờ debug:

Điều bất ngờ Vì sao Chi tiết
Tab tên "notifications" lại là danh sách chat Đặt tên di sản Messaging
App chủ động ngắt socket khi xuống nền Server chỉ push cho người offline — không ngắt thì không có thông báo tin nhắn Notifications
requestPermission() của Firebase không hỏi gì trên Android Hàm đó là @platform ios; Android 13+ phải dùng PermissionsAndroid Notifications
Có hai đường upload file (axios và fetch) axios 1.x trên RN gửi FormData rỗng → ERR_NETWORK Kiến trúc
Đăng nhập Google và FCM ở hai project Google khác nhau Chúng độc lập hoàn toàn Setup
Không có GET /blogs/{id} Chi tiết bài phải tìm trong feed → bài cũ không mở được Blog
Bình luận giọng nói chỉ là giao diện rỗng Chưa có ghi âm, chưa có upload, chưa có phát Blog
Dạng sóng ở phòng thu là số ngẫu nhiên Không có FFT, không đọc metering Challenge
is_premium = true không có nghĩa là đang có Premium Phải so premium_expired_at với hiện tại Payments
Ngân sách job nhập theo triệu ở màn tạo, theo VND ở màn sửa Hai màn dùng đơn vị khác nhau cho cùng một trường Jobs
Duyệt đơn ở màn này không làm mới màn kia jobs và collab có cache tách biệt cho cùng một API Collab
Có hai màn "Explore" khác nhau (tabs)/explore tìm người, (challenge)/explore tìm beat Explore
Đổi EXPO_PUBLIC_STORAGE_* làm mọi user bị đăng xuất Dữ liệu MMKV cũ không giải mã được Công nghệ
Bản build từ CI có thể không gọi được API .env bị loại khỏi gói EAS — cần cấu hình biến môi trường trên EAS Setup, mục 8.6
